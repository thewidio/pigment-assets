# Vigéa

Bannières issues du kit d'identité Vigéa (voir le kit source pour le détail
palette / typographie). Seuls les exports bannière existaient au moment de la
publication — pas de logo seul ni de favicon disponibles séparément.

| Fichier | Format | Usage |
|---|---|---|
| `vigea-banner-wide-light.png` / `.svg` | 2700×450 | Bandeau pleine largeur, fond clair. À poser au-dessus d'étapes de process Pigment. |
| `vigea-banner-wide-dark.png` / `.svg` | 2700×450 | Idem, fond sombre. |
| `vigea-footer-light.png` | 2700×240 | Pied de page de board : part de la teinte du bas de la bannière claire (`#F6F8FD` à gauche, `#EFF3FB` à droite) et fond vers le blanc pur. À poser en dernier widget, pleine largeur ; un texte placé juste dessous se lit comme intégré. |

Préférer le `.svg` si l'usage le permet (mise à l'échelle sans perte) ; le
`.png` est fourni pour les widgets qui n'acceptent pas le SVG.

## Accueil de l'application VIGÉA RH (board b0)

Générés par `generer_b0.py` (dépôt Wilde.ai, `internal/VIGEA-RH/05 Technical Solution/02 User experience/reference/assets-b0/`), Raleway, couleurs du kit Vigéa. Tailles calées sur une grille de board de 12 colonnes (225 px par colonne, 45 px par rangée, rendu ×2) : poser en widget Image, ajustement « Fill », à la taille indiquée.
