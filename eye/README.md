# EYE Asset Management

Société fictive (démonstration). Assets construits par rendu HTML/CSS fidèle
à la charte (`eye-identite-visuelle-v2.html` : lockup Inter Tight 700 + filet
rouge `#CE1B2B` + libellé `Asset Management` en Inter Tight 300 gris ardoise) —
aucun élément inventé hors de cette charte, seulement rasterisé.

| Fichier | Format | Usage |
|---|---|---|
| `eye-logo-transparent.png` | ~700×230, fond transparent | Texte encre foncée — pour poser sur fond clair (cartes/tableaux Pigment). |
| `eye-logo-on-dark.png` | ~700×230, fond transparent | Texte clair (bone) — pour poser sur fond sombre. |
| `eye-logo-white-bg.png` | fond blanc plein | Version autoportante si le widget ne supporte pas la transparence. |
| `eye-banner-wide.png` | 2700×450, fond encre | Bandeau pleine largeur, logo centré — au-dessus des étapes d'un process Pigment. |
| `eye-favicon-32/180/512.png`, `eye-favicon.ico` | carré, fond rouge `#CE1B2B` | Favicon / icône d'application. |
