# pigment-assets

Assets visuels (images, bannières) hébergés publiquement pour être référencés
par URL directe dans Pigment (widgets image, en-tête de process, favicon
d'application) — Pigment ne peut pas lire un fichier privé sans authentification,
d'où ce repo public dédié.

**URL brute d'un fichier** : remplace `<fichier>` ci-dessous.

```
https://raw.githubusercontent.com/thewidio/pigment-assets/main/<fichier>
```

Exemple : `https://raw.githubusercontent.com/thewidio/pigment-assets/main/mnh/mnh-banner-wide.png`
