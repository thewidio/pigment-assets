# MNH (Mutuelle Nationale des Hospitaliers)

Client réel. Assets dérivés mécaniquement des logos officiels partagés
(`logo-MNH.png`, avatar carré fond marine) — aucune forme redessinée, seulement
détourage, recoloration du monogramme (marine → blanc sur fond sombre, accent
rose conservé) et redimensionnement.

| Fichier | Format | Usage |
|---|---|---|
| `mnh-logo-white-bg.png` | fond blanc plein | Logo officiel tel que fourni, redimensionné. |
| `mnh-logo-transparent.png` | fond transparent | Détouré depuis le logo officiel — pour poser sur fond clair. |
| `mnh-logo-on-dark.png` | fond transparent, monogramme blanc | Pour poser sur fond sombre. |
| `mnh-banner-wide.png` | 2700×450, fond marine | Bandeau pleine largeur — au-dessus des étapes d'un process Pigment. |
| `mnh-banner-wide-light.png` | 2700×450, fond blanc | Idem, fond clair. |
| `mnh-favicon-32/180/512.png`, `mnh-favicon.ico` | carré, fond marine | Favicon / icône d'application (recadré depuis l'avatar officiel). |

Couleurs mesurées sur le logo source : marine `#005690`, rose `#E23E84`,
fond marine de marque `#2A3179`.
